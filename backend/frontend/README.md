# TaskFlow Pro

## 📌 Descrição

Sistema web de gerenciamento de tarefas com controle de prioridades, status e dashboard.

## 🚀 Funcionalidades

* Criar tarefas
* Editar tarefas
* Excluir tarefas
* Marcar como concluída
* Pesquisa de tarefas
* Filtro por status
* Dashboard com estatísticas

## 🧱 Tecnologias

* HTML
* CSS
* JavaScript
* Node.js
* Express
* SQLite

## 🏗️ Arquitetura

Frontend: HTML + CSS + JS
Backend: Node.js + Express
Banco de dados: SQLite

## 👨‍💻 Objetivo

Aplicar conceitos de desenvolvimento web com arquitetura em 3 camadas e CRUD completo.
